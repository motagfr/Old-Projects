# What’s in This Repo?

Hey there! Welcome to my little corner of projects. This repo’s got a mix of stuff—some deep learning, some machine learning, and a bunch of programming experiments I had fun with. Here’s how it’s all laid out:

## What’s Inside?

1. **Data Visualization**:
   - `First_1000_Prime_Numbers.txt`: A list of the first 1000 prime numbers. Handy for math stuff or just to geek out.
   - `GRAPH.ipynb`: A notebook for making and analyzing graphs. It’s all about telling stories with data.
   - `MatplotlibCourse.py`: Learn Matplotlib with this script. It’s got scatter plots, histograms, and tips to make your plots pop.
   - `Numpy6.py`: Some NumPy magic here—finding roots, extrema, and visualizing them.
   - `Visualization_Primes.py`: A fun way to see how prime numbers are spread out. Uses line plots and histograms. *It uses the numbers from `First_1000_Prime_Numbers.txt`.*
   - `Visualization_Primes2.py`: Another take on prime number visuals, but with grids and custom colors. *Also uses `First_1000_Prime_Numbers.txt`.*

2. **Deep Learning and Machine Learning**:
   - `FashionMNIST_Model.py`: A project to train a neural network to recognize clothes from the Fashion MNIST dataset. Covers data prep, training, and testing.
   - `Intel_Image_Classification.py`: Classifies images using the Intel Image Dataset with a CNN. *Dataset link: [Kaggle](https://www.kaggle.com/datasets/puneet6060/intel-image-classification).* 
   - `Machine Learning & Data Processing.ipynb`: A mix of ML goodies—KNN, linear regression, logistic regression, and more. Plus, some data viz.
   - `MachineLearning.py`: Covers multiple ML algorithms like KNN, linear regression, and regularized models. Also has data viz and evaluation metrics.
   - `transfer_learning.ipynb`: Shows how to use pre-trained models for new problems. *Found this one online, didn’t make it myself.*

3. **Other Cool Stuff**:
   - `mergeSortDescending.py`: Sorts a list in descending order using merge sort. Simple and neat.
   - `OptimizedPython.py`: A faster bubble sort that stops early if the list’s already sorted.
   - `Pandas.py`: A hands-on script for learning Pandas. Covers Series, DataFrames, and data manipulation.
   - `printTwoElements.py`: Finds the repeating and missing numbers in a list. Includes a basic and a smarter approach.

4. **Docs**:
   - `README.md`: This file! It’s your guide to what’s in here.

## Heads Up

These files are for fun and learning. They might be a bit messy since I didn’t plan to share them when I made them. Hope you enjoy exploring!
